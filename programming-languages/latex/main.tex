\section*{Programme Overview}
\addcontentsline{toc}{section}{Programme Overview}
This curriculum builds \textbf{polyglot engineers} who can choose and use the right language for each layer of a modern
enterprise and AI product. Each course follows the same five-unit arc:
\emph{foundations $\rightarrow$ core language design $\rightarrow$ concurrency and performance $\rightarrow$ services and
data $\rightarrow$ production, cloud and AI integration}. Every unit ends with a concrete \textbf{hands-on outcome}, and every course
pairs 45 lecture hours with 30 laboratory hours and ends in an enterprise capstone.

\section*{Why These Five Languages for 2026--2035}
\addcontentsline{toc}{section}{Why These Five Languages for 2026--2035}
Modern products are \textbf{polyglot}. A typical AI product uses Python for models and agents, Java or Go for business services,
Scala for large data pipelines, and Rust for the fast, safe core. Together these five languages cover every layer an engineer will
meet between 2026 and 2035.

Python & Fast to write, huge library ecosystem, readable & Language of AI models, LLM apps, agents and data science & AI, analytics, research, automation\\
\rowcolor{navylight} Go & Simple, fast compile, built-in concurrency & Infrastructure that hosts and scales AI: gateways, agents, operators & Cloud, SaaS, DevOps, telecom\\
Rust & Memory safety without garbage collection, C-level speed & Safe, fast engines: inference, tokenisers, data engines, edge AI & Systems, security, automotive, blockchain\\

\csec{Engineering Outcomes Expected by 2030--2035}
\begin{itemize}
\item \textbf{AI-assisted programming is normal:} engineers direct coding assistants and agents, so reading code, reviewing it, testing it and designing systems matter more than typing it.
\item \textbf{Polyglot by default:} graduates move between Python, a JVM language and a systems language within one product.
\item \textbf{Memory safety and secure-by-design:} new critical software increasingly uses memory-safe languages such as Rust, Go and Java.
\item \textbf{Concurrency everywhere:} virtual threads, goroutines, async Rust and effect systems are core skills for scalable AI services.
\item \textbf{Specification and verification:} types, tests and evaluation suites become the way humans control AI-written code.
\end{itemize}

\csec{Industry Certification Policy}

Some languages (Go and Rust) have no official language-level exam, so cloud-native certifications, accredited training and GitHub
portfolio assessment are listed instead. Python Institute exams are moving to new versions during 2026. Learners should confirm the
current exam code on the issuer's website before registering.}
